# Awesome Design Skills — Curated Style Archetypes

Use this skill to reference and apply a specific, cohesive visual archetype rather than a generic template.

## Available Style Archetypes (in `./references/`)

1. **Terracotta (`./references/terracotta.md`)**:
   - Sun-baked, clay-toned editorial interface built on warm cream surfaces (`#FBF8F3` / `#F3E9D8`), ink-brown headlines set in a display serif, and a warm terracotta accent (`#C56A3C` / `#B84A27`).
   - Best for: Human-centered storytelling, community/social impact projects, documentary archives, cultural publications.
2. **Editorial (`./references/editorial.md`)**:
   - Magazine-inspired editorial layout with refined serif typography, structured multi-column grids, 8pt baseline rhythm, drop caps, pull quotes, and high-contrast reading experiences.
3. **Storytelling (`./references/storytelling.md`)**:
   - Narrative-driven design using visuals, progressive copy, timeline milestones, and chapter transitions to guide users through emotionally resonant journeys.
4. **Bento (`./references/bento.md`)**:
   - Structured modular grid layouts with varied card spans (`col-span-2`, `row-span-2`) for showcasing metrics, highlights, and multimedia galleries without monotony.
5. **Paper (`./references/paper.md`)**:
   - Tactile, archival paper surfaces with subtle hairlines, ink borders, and print-inspired metadata tags.
6. **Refined (`./references/refined.md`)** & **Impeccable (`./references/impeccable.md`)**:
   - High-craft spacing, micro-borders, optical alignment, and restrained luxury polish.

## Combined Archetype for Dự Án CHO EM: `Terracotta + Editorial + Storytelling + Bento`

- **Surface Palette**: Warm Archival Paper (`#FBF8F3`), Sunlit Sand (`#F4EFE6`), Warm Card (`#EFE7DA`), Deep Forest Ink (`#1F3A2E`), Highland Terracotta (`#B84A27`), Sun Gold (`#D98A2B`).
- **Typography**: Display serif (`Fraunces`) for chapter headings, pull quotes, and impact metrics (`font-variant-numeric: tabular-nums`), paired with clean Vietnamese-native humanist sans (`Be Vietnam Pro`).
- **Editorial Anatomy**:
  - Chapter numbers (`01`–`07`), season stamps, location badges, and verifiable financial/impact ledgers.
  - Asymmetric Bento photo grids where the lead documentary photograph commands 2×2 space alongside close-up portraits.
  - Pull-quotes with serif display italics and archival source attribution.
